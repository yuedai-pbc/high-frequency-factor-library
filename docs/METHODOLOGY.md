# 股票高频因子库：构建思路

## 重建交易时间

区分集合竞价、连续交易与午间休市；交易、报价和订单按时间戳对齐，处理撤单及重复消息。

## 定义时段特征

跨日保持相同 slot；先结束形成窗口，再预测下一时段。日内、隔夜按同一复权口径计算。

## 检验机制

以消息强度作为 AT 代理，研究其与流动性、时段反转的关系；因果检验需另行论证识别条件。

## 模拟可成交结果

纳入买卖价差、延迟、冲击与限价约束；A 股回测需检查当日可用持仓和 T+1 约束。

## 研究协议

1. 先登记定义、预期方向、形成窗口和假设，再观察评价区间结果。
2. 分别保存观测时间、公告可得时间、决策时间和执行时间；修订财报保留版本。
3. 训练、选择超参数、决定因子方向均使用过去数据；重叠标签窗口需要留出隔离区间。
4. 在同类资产内评价；报告缺失率、覆盖率、相关性与风险暴露，避免把变体数量当成独立信号。
5. 原始和中性化信号并行保存；标准化不得跨时间混合未来样本。
6. 评价同时看预测质量和实施成本，保留无效或负结果。

## 经济逻辑的证据等级

因子卡片标注来源和状态。经济解释属于待检验假设；文献统计显著性、代码存在、复现通过、成本后有效是四种不同证据。
