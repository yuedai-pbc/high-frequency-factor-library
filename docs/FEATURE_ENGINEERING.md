# 股票高频因子库：特征工程与泛化

计划优先选择 8 个种子，每个保留 8–16 种允许表达，含原始表达。候选列预算为 **64–128**，其中相对单一基础表达新增 **56–120** 列。这是假设数据齐备下的工程范围，不是有效因子预测。

## 优先顺序

当前 9 个研究条目先归并成约 8 个基础种子；消息相关代理定义与真实 HFT 账户标签分开。

## 窗口

交易日内 5/15/30/60 分钟与开盘、收盘时段；跨日同一时段 5/20 日历史基线。窗口嵌套只保留有信息差异的版本。

## 变换

同窗口基础量 → 日内季节性残差 → 过去同时间段 z 分数 → 滞后变化 → 买卖方向/交易时段条件统计。8–16 是每个种子允许的总版本数，不是全排列。

## 实例

消息强度：消息数/成交额 → 15/30 分钟版本 → 过去 20 日同槽位标准化 → 开盘与尾盘差 → 单独考察流动性条件下的变化。

## 数据条件

需要逐笔或稳定分钟数据、交易所时间戳、接收时间戳、消息定义与历史交易时段。只有日线数据无法实现这一预算。

## 泛化验证

交易时段归一化后做跨月、跨股票、跨交易所留出；训练和测试之间隔离重叠窗口，使用下一可成交报价评价。

## 种子分配（计划）

| 家族 | 种子数 |
|---|---|
| 时段收益 | 3 |
| 消息与交易强度 | 2 |
| 波动与效率 | 2 |

## 统一工程流程

1. 建立种子注册表：经济假设、原文版本、原始公式、适用资产、方向、输入可得时间、单位和缺失处理。当前目录只是来源条目，先做语义与公式去重再选择种子。
2. 用白名单登记允许的窗口、归一化、差分、条件残差及交互；每个候选列生成唯一 ID。示例：`asset__family__base__window__transform__v1`。参数改动必须留版本，不做任意笛卡尔积。
3. 同时保存 observation_at、available_at、decision_at、execution_at。同一时点横截面排名只可使用当时可得资产；时间序列均值、回归系数、去极值阈值和 PCA 载荷仅用训练历史。
4. 划分时间滚动训练、验证和最终封存测试。根据预测标签持有期剔除训练末端重叠标签；序列重叠的特征窗口和分组关系也纳入隔离设计。测试集不能用于调方向、阈值或版本数。
5. 先做确定性去重：同公式、同输入、仅换单位或严格单调表达不计为独立经济信号。保留替代表达试验时显式标记。再在训练样本内按相关性聚类，阈值如 |Spearman|>0.95 仅作为待预登记的工程起点。
6. 比较基准模型与“基准 + 单个家族”：预测增量、家族消融、覆盖率、稳定性、换手及成本同时报告。使用多重检验/FDR 或家族层级筛选，并保留全部尝试日志，不能只展示成功版本。
7. 跨市场泛化先保留经济定义，再匹配单位、日历、时点和交易约束；只有训练期决定的适配规则能进入样本外。跨资产交互须先有机制假设。

## 三种数量分别管理

- 来源条目数：当前目录中的文献定义、变体、风险度量及核算条目；包括可能重复概念。
- 候选特征列预算：选定种子数 × 每种子允许的总版本数，包含基础表达。下面的数量是建设范围估算，尚未生成真实数据列。不是当前目录数量的机械倍增，也不能与目录数量直接相加。
- 筛选后保留数 / 有效因子数：由数据覆盖、公式去重、相关聚类、跨市场与成本后样本外检验决定。目前无法可靠预估，更不能把预算当成 alpha 数量。

## 两阶段建设

第一阶段采用每库较低版本预算，优先使用已明确可得的数据。第二阶段只在基础复现和数据质量达标后，扩充到较高版本预算；高端预算依赖逐笔、完整公告历史或多期限曲线等新增数据。所有交互项占用已有版本预算，不额外无限叠加。

跨库相同经济信号不会因为出现在不同资产库就被认定为独立。数据质量标记、风险缩放与损益核算独立存储，不计入预测信号的种子预算。
